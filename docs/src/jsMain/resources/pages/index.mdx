<ktjs-features section-title="Why write animations in Kotlin" tinted>

<ktjs-feature icon="lucide:calendar" title="Typed options">`calendarOptions { … }` is an interface: a misspelled option is a compile error, and `plugins` takes the real plugin values.</ktjs-feature>

<ktjs-feature icon="lucide:layout-grid" title="Every open-source view plugin">day grid, time grid, multi-month, list, interaction and the bundled `all` plugin, each bound from its own sub-path.</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="Events and the calendar API">`addEvent`, `getEventById`, `getEvents`, event sources, view switching, navigation and date formatting all speak typed Kotlin.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in Chromium">The module's tests create real calendars against the real library, and the demo has its own Playwright suite covering views, buttons and the language switch.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">Every page exists in English and Simplified Chinese, with the same structure, and links out to the demo and the Dokka reference.</ktjs-feature>

</ktjs-features>
