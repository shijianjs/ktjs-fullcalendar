<ktjs-features section-title="为什么用 Kotlin 写前端动画" tinted>

<ktjs-feature icon="lucide:calendar" title="带类型的选项">`calendarOptions { … }` 是接口：拼错的选项就是编译错误，`plugins` 收的是真正的插件值。</ktjs-feature>

<ktjs-feature icon="lucide:layout-grid" title="全部开源视图插件">day grid、time grid、multi-month、list、interaction 以及打包好的 `all` 插件，各自从对应子路径绑定。</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="事件与日历 API">`addEvent`、`getEventById`、`getEvents`、事件源、视图切换、翻页与日期格式化全部是带类型的 Kotlin。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="在 Chromium 里测试">模块的测试对着真实库创建真实日历，演示页另有 Playwright 套件，覆盖视图、按钮与语言切换。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">每个页面都有英文与简体中文两版，结构一致，并各自跳转到演示页与 Dokka API 文档。</ktjs-feature>

</ktjs-features>
